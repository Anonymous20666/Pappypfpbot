# Pappypfpbot

WhatsApp Group PFP Manager & Universal Media Bot powered by Telegram.

## Setup

```bash
npm install
cp .env.example .env
# Edit .env with your BOT_TOKEN, OWNER_ID, MONGODB_URI, REDIS_URL
npm start
```

## Requirements

- Node.js >= 20
- MongoDB
- Redis (optional, for auto-change scheduler)
